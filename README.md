**Welcome to your local Pharma Care Hub project**

**About**

Esta aplicación está configurada para ejecutarse totalmente en local sin dependencia de Base44.

**Edita el código en tu entorno local**

1. Clona el repositorio usando la URL del proyecto.
2. Entra en el directorio del proyecto.
3. Instala dependencias: `npm install`
4. Ejecuta la aplicación: `npm run dev`

Run the app: `npm run dev`

**Nota**

Ya no se requiere Base44 ni configuración de entorno para `VITE_BASE44_APP_ID` o `VITE_BASE44_APP_BASE_URL`.
